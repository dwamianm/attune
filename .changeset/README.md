# Changesets

Each change to a library package that users should know about gets a
changeset: run `pnpm changeset`, pick the packages, the bump (patch,
minor, or major), and write one line about the change. The four
`@attuneui/*` packages always release together at one version (`fixed`
in config.json). The apps are private and never released.

Releasing is in the root README, under "Publish".
